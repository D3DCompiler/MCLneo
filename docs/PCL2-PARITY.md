# PCL2 功能对照与路线图

> 目标不是逐行复刻 PCL2，而是把 PCL2 用户真正依赖的工作流迁移到一个独立、可维护的实现里。
> 状态标记：✅ 已实现并验证 · 🟡 已实现待补强 · ⚪ 计划中 · ⛔ 暂不在范围内

## 9. 与 PCL2 的明确差异

- **不复制 PCL2 代码和素材**，因此 UI、配置格式和内部实现不同。
- **联机邀请码不兼容**；PCL2 房间和 MCLneo 房间不能互相加入。
- **不保证读取 PCL2 的设置**；只通过标准 `.minecraft/versions` 复用游戏版本。
- 当前版本没有正版登录，不能加入需要正版验证的服务器；离线账户只能用于离线/局域网场景。
- Forge/NeoForge 已接入；依赖 OptiFine/CurseForge 的整合包仍需额外适配。
